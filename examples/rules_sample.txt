# 拒收规则示例（每行一条：编号 | 比较式，规则内比较同时成立）
# 字段：毛重 / 托盘重 / 申报净重（克）；比较符 = != > >= < <=
# 直接复制到网页“规则录入”框，范围取 0 ~ 1000000 即可试算

# 净重差 = 毛重 - 托盘重 - 申报净重
R001 | 毛重 - 托盘重 - 申报净重 > 500
R002 | 毛重 - 托盘重 - 申报净重 < -500
# R003 的可行域是 R002 的子集：只能连带 R002 触发
R003 | 毛重 - 托盘重 - 申报净重 < -1000
# 毛重低于托盘重（物理不可能的录入）
R004 | 毛重 < 托盘重
# 多条件同时成立：净重差恰好为 0 且毛重不超过 10000
R005 | 毛重 - 托盘重 = 申报净重；毛重 <= 10000
# 超过范围上界：在 0~1000000 范围内从不触发
R006 | 毛重 > 1000000
